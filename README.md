
# 📚 Link Librarian

Smart bookmarking with context - Never forget why you saved a link again!

## Features

    🎯 Smart Context Saving

    - Save links with the exact quote that caught your attention
    - Right-click context menu integration
    - Automatic page metadata extraction
    - Visual feedback on save

    🔍 Intelligent Search
    
    - Search through titles, quotes, domains, and tags
    - Real-time search with highlighting
    - Relevance-based sorting, Prioritizes matches in titles and quotes
    - Lightning-fast results

    🏷️ Flexible Organization
    
    - Add custom tags to categorize links
    - Filter by All, Recent, or Tagged
    - Bulk organization tools
    - Comma-separated input: Easy tag entry
    - Visual tag display: Color-coded tag system
    - Tag-based filtering: Quick access to tagged content
    - Bulk operations: Manage multiple links efficiently

    ✨ Modern Interface
    
    - Dark theme with glassmorphism effects
    - Smooth animations and transitions
    - Responsive design
    - Accessibility-first approach
    
    
## Quick Start

### Installation

#### Download the Extension

    git clone https://github.com/yourusername/link-librarian.git
    cd link-librarian

#### Load in Chrome

    - Open Chrome and navigate to chrome://extensions/
    - Enable "Developer mode" (top right toggle)
    - Click "Load unpacked" and select the extension folder
    - The icon should appear in your toolbar
    - Start Saving!

#### Highlight text on any webpage
    - Right-click and select "Save Link with Context"
    - Access your library by clicking the extension icon
